매출 정리, 목록 정리, 견적서, 리뷰 답글, 가격 비교까지. 설치 없이 인터넷 창에서 바로 쓰는 업무자동화 프로그램이에요.

v1.3 깃허브판 · 작성자 윤남주

흩어진 매출, 한 장으로

판매처에서 내려받은 엑셀(.xlsx)이나 CSV 파일을 올리세요. 날짜와 금액 칸을 자동으로 찾아요.

1. 파일 올리기

엑셀 읽기 기능을 불러오는 중…

2. 직접 입력 (현금·계좌이체 등)

3. 한 장 정리 결과 예시 데이터

웹페이지 목록 → 엑셀 자동 정리

블로그·쇼핑몰 목록 화면을 마우스로 끌어 복사(Ctrl+C)한 뒤 아래에 붙여넣으세요(Ctrl+V).

정리 결과

날짜별 글 수

이 도구는 붙여넣은 글만 정리해요. 다른 사이트에 직접 접속해 긁어오지 않으니 사이트에 부담을 주지 않아요.

견적서 자동 작성

품목만 넣으면 공급가액·부가세·합계와 한글 금액이 자동으로 채워져요.

미리보기

리뷰 답글 초안

리뷰를 붙여넣으면 칭찬·보통·불만을 구분해서 답글 초안을 만들어요. 그대로 올리지 말고 한 번 읽고 가게 상황에 맞게 고쳐 쓰세요.

경쟁사 가격 비교

경쟁사 가격을 확인할 때마다 적어 두세요. 내가 더 비싼 상품이 위로 올라와요.

비교 결과 예시 데이터

기준: 경쟁사보다 3% 넘게 비싸면 '비쌈', 3% 이내면 '비슷', 더 싸면 '저렴'으로 표시해요.

백업·기기 옮기기

기록은 지금 쓰는 기기에 저장돼요. 다른 기기로 옮기거나 혹시 모를 때를 대비해 백업해 두세요.

방법 1. 백업 파일 (추천)

내 기록을 파일 하나로 저장해요. USB·카톡 PC버전·메일로 옮긴 뒤, 다른 기기에서 그 파일을 고르면 그대로 불러와요.

기록은 이 기기 인터넷 창에 저장돼요

방법 2. 백업 코드 (휴대폰에 편해요)

코드를 복사해 카톡 '나와의 채팅'이나 메모로 보내고, 다른 기기에서 붙여넣으면 똑같이 옮겨져요.

지금 이 기기의 기록

옮겨지는 것: 매출 기록, 가격 기록, 견적서 정보(가게 이름·품목).
옮겨지지 않는 것: 목록 정리·리뷰 입력칸(한 번 쓰고 끝나는 내용).

기록은 각자 기기에만 저장돼서, 앱 주소를 다른 사람에게 공유해도 내 기록은 보이지 않아요. 인터넷 사용 기록을 지우면 기록도 지워지니 가끔 백업해 두세요.

사용법

메뉴마다 그림 속 빨간 번호 순서대로 따라 하시면 돼요.

처음 한 번만

  1. PC에서 이 앱 주소를 열고 Ctrl+D를 눌러 즐겨찾기에 넣어 두세요. 다음부터 즐겨찾기에서 바로 열려요.
  2. 로그인은 필요 없어요. 기록은 지금 쓰는 기기에 저장되고, 다른 기기로 옮길 땐 ⑥ 백업·옮기기를 써요.
  3. 처음에 보이는 숫자는 예시 데이터예요. 내 기록을 하나라도 넣으면 예시는 사라져요.

① 매출 정리

  1. 판매처(쿠팡·스마트스토어 등)에서 매출 엑셀이나 CSV를 내려받아 파일 선택을 눌러 올려요. 여러 개를 한꺼번에 골라도 돼요.
  2. 파일마다 날짜 칸·금액 칸이 자동으로 골라져요. 맞는지 보고, 판매처 이름을 확인한 뒤 이 파일 합치기를 눌러요.
  3. 오른쪽 위 월 선택에서 보고 싶은 달을 고르면 합계·판매처별 막대·표가 바뀌어요.
  4. 표 복사를 누르고 엑셀 빈칸에 붙여넣기(Ctrl+V) 하면 끝. 엑셀 파일로 저장도 돼요.

현금·계좌이체처럼 파일이 없는 매출은 왼쪽 2. 직접 입력에 날짜·금액을 넣고 추가하세요.

② 목록 정리

  1. 블로그·쇼핑몰 목록 화면을 마우스로 끌어 선택하고 Ctrl+C로 복사한 뒤, 큰 입력칸에 Ctrl+V로 붙여넣어요.
  2. 정리하기를 누르거나 Ctrl+Enter를 눌러요.
  3. 오른쪽에 번호·날짜·제목으로 나뉜 표와 날짜별 글 수가 나와요.
  4. 표 복사로 엑셀에 붙여넣어요.

특정 단어(예: 후기)가 들어간 줄만 보고 싶으면 "이 단어가 있는 줄만" 칸에 적으세요.

③ 견적서

  1. 우리 가게 이름·연락처·받는 분을 적어요. 한 번 적으면 다음에도 기억해요.
  2. 품목·수량·단가를 적어요. + 품목 추가로 줄을 늘려요.
  3. 오른쪽 미리보기에 공급가액·부가세·합계와 한글 금액이 바로 채워져요.
  4. 견적 내용 복사로 문자·카톡·엑셀에 붙여넣어요.

부가세 칸에서 "별도/포함/없음"을 고르면 계산이 알맞게 바뀌어요.

④ 리뷰 답글

  1. 가게 이름과 말투(다정하게/정중하게)를 고르고, 리뷰를 한 줄에 하나씩 붙여넣어요.
  2. 답글 만들기를 눌러요.
  3. 리뷰마다 칭찬·보통·불만 표시와 답글 초안이 나와요. 불만은 빨간색이라 먼저 챙기기 좋아요.
  4. 답글 복사를 눌러 스토어 답글 칸에 붙여넣어요.

올리기 전에 꼭 한 번 읽고 가게 상황에 맞게 고치세요. "AI로 다듬기"는 처음 누를 때 사용 허락을 물어요.

⑤ 가격 비교

  1. 상품명, 내 가격, 경쟁사 이름, 경쟁사 가격을 적어요.
  2. 기록하기를 눌러요. 같은 상품을 다시 기록하면 최신 가격으로 바뀌어요.
  3. 상태가 비쌈(빨강)·비슷(주황)·저렴(초록)으로 표시되고, 비싼 상품이 맨 위로 올라와요.
  4. 표 복사로 엑셀에 옮겨 보관해요.

경쟁사보다 3% 넘게 비싸면 "비쌈"으로 표시돼요.

⑥ 백업·옮기기

  1. 백업 파일 저장을 누르면 내려받기 폴더에 "구경GO_백업_날짜.txt" 파일이 생겨요.
  2. 휴대폰으로 옮길 땐 백업 코드 복사를 눌러 카톡 '나와의 채팅'에 붙여넣어 보내요.
  3. 다른 기기에서 앱을 열고 백업 코드를 붙여넣은 뒤 이 기기로 불러오기, 또는 백업 파일을 골라요.

옮겨지는 것: 매출 기록, 가격 기록, 견적서 정보. 불러오면 그 기기의 기존 기록은 백업 내용으로 바뀌어요.
